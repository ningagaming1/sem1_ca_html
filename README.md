TITAN'S FITNESS CENTER

A beginner-friendly **gym management system frontend** built using HTML5 and CSS3. This project demonstrates how a gym can organize its member information, membership plans, workout schedules, attendance history, and administrative dashboard through a simple, user-friendly interface.

Project Overview

Titan's Fitness Center Management System is a website designed to represent the interface of a gym management application. 

Objectives

: Design a simple and user-friendly gym management interface.
: Create multiple interconnected webpages using HTML.
: Demonstrate HTML forms, tables, hyperlinks, and input validation.

Features

### 🔐 Login Page
: Email and password input fields.
: Admin and Staff role selection interface.
: Basic HTML form validation.

### 📊 Admin Dashboard
: Total members overview.
: Active memberships summary.
: Daily attendance overview.
: Upcoming workout sessions.
: Recent member activity table.

### 👥 Member Management
: Sample member records.
: Member registration form.
: Membership plan selection.
: Search and status-filter controls in the interface.

### 📅 Schedules and Membership Plans
: Weekly workout timetable.
: Trainer and session details.
: Membership plan presentation.
: Sample schedule creation form.

### 📈 Progress and History
; Sample attendance history.
: Workout records and fitness progress.
: Member status information.
: Simple visual progress indicators.

## 🛠️ Technologies Used

 : HTML5— webpage structure and content.
 : CSS3— styling, layouts, colors, and responsive design.
